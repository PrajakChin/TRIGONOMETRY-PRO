TRIGONOMETRY PRO V13.0.5 — FULL-WIDTH INPUT AREA

แก้ไขตามภาพที่ผู้ใช้วงกรอบสีแดง:
- สาเหตุเดิม: #geoInputs ใช้คลาส .fields ซึ่งเป็น CSS Grid สองคอลัมน์ ทำให้ภาพและช่องกรอกกินพื้นที่เพียงครึ่งหนึ่ง และข้อความคำแนะนำไปอยู่คอลัมน์ขวา
- เปลี่ยนส่วนกรอกขนาดให้เป็น block เต็มความกว้างของการ์ด
- ขยายพื้นที่แผนภาพเป็น 300px สูง และให้ SVG กินเต็มพื้นที่
- คงตำแหน่งแบบเปอร์เซ็นต์และขนาดช่องกรอกเดิม
- คำแนะนำย้ายลงมาอยู่ใต้ภาพ ไม่เบียดพื้นที่ด้านข้าง
- ส่วนภาพประกอบรูปทรงด้านล่างยังเป็นส่วนเดียวที่อัปเดตเรียลไทม์
- ภาพในส่วนกรอกข้อมูลยังคงเป็นภาพนิ่ง

ตรวจสอบ JavaScript syntax ผ่าน node --check แล้ว
