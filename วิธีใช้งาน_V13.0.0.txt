TRIGONOMETRY PRO V13.0.0 — LIVE GEOMETRY PREVIEW

พัฒนาต่อยอดจาก V12.9.0 โดยคงรูปแบบช่องกรอกที่วางบนภาพไว้

เพิ่ม:
- ภาพตัวอย่างในส่วนภาพประกอบรูปทรงอัปเดตทันทีเมื่อแก้ไขช่องตัวเลข
- ป้ายค่าที่กรอกแสดงใต้ภาพและใช้สีแยกตัวแปร
- รูปทรง 2D/3D ปรับสัดส่วนภาพตัวอย่างตามค่าที่กรอก (เป็นภาพ preview เชิงสัดส่วน)
- รูปหลายเหลี่ยมไม่สม่ำเสมอสร้างภาพจากพิกัด X,Y แบบเรียลไทม์
- เส้นทแยงมุมของรูปหลายเหลี่ยมแสดงเป็นเส้นประหลายสีระหว่างกรอกพิกัด
- เมื่อเปลี่ยนข้อมูล จะแจ้งให้กดคำนวณใหม่เพื่ออัปเดตค่าผลลัพธ์และวิธีทำ
- การคำนวณ สูตร หน่วย และวิธีทำเดิมยังทำงานผ่านปุ่มคำนวณตามเดิม

ข้อควรทราบ:
ภาพ Preview ของรูปทรงทั่วไปเป็นการปรับสัดส่วนโดยประมาณเพื่อช่วยมองเห็น ไม่ใช่การสร้างแบบจำลองทางเรขาคณิตเต็มรูปแบบจากทุกตัวแปร
สำหรับรูปหลายเหลี่ยมไม่สม่ำเสมอ ภาพสร้างจากพิกัดจริงที่กรอก

ตรวจสอบ:
- JavaScript syntax ผ่าน node --check
- ทดสอบตรรกะการแสดงภาพจากข้อมูลที่เปลี่ยนในโค้ดแล้ว
- ควรทดสอบการใช้งานจริงบน Android โดยเฉพาะตำแหน่งช่องกรอกและการเลื่อนหน้าจอ
