ฐานพัฒนา: V11.9.0
รักษาหน้าตาและฟังก์ชันตรีโกณมิติ กราฟ ประวัติ สามเหลี่ยม วิธีทำละเอียด ระบบสี ภาพกรอกข้อมูลคงที่ และภาพผลลัพธ์ตามสัดส่วน

เพิ่มเมนูเครื่องมือวิศวกรรม 2D/3D:
1. ระยะทางระหว่างจุด P และ Q ใน 2D/3D
   d = √Σ( qi - pi )²
2. เวกเตอร์และขนาดเวกเตอร์
   |u| = √(ux² + uy² [+ uz²])
3. Dot Product
   u·v = uxvx + uyvy [+ uzvz]
4. มุมระหว่างเวกเตอร์
   θ = cos⁻¹[(u·v)/(|u||v|)]
5. แสดงสูตร การแทนค่า ขั้นตอน และคำตอบ
6. ตรวจช่องกรอกว่างและกรณีเวกเตอร์ศูนย์

การทดสอบ:
- JavaScript syntax ผ่าน
- 2D distance (3,4) = 5
- 3D vector magnitude (1,2,2) = 3
- 3D dot product (1,2,3)·(4,5,6) = 32
- มุมระหว่างเวกเตอร์ตั้งฉาก = 90 องศา

หมายเหตุ:
- รุ่นนี้เป็นขั้นแรกของชุดเครื่องมือวิศวกรรม 2D/3D
