TRIGONOMETRY PRO V13.0.2 — ALL SHAPES LIVE PREVIEW

แก้ไขจาก V13.0.1 เนื่องจากพบว่าการปรับภาพเดิมครอบคลุมเฉพาะรูปทรงบางชนิด

สิ่งที่ปรับ:
- ใช้ระบบ preview กลางสำหรับรูปทรง 2D และ 3D ทุกชนิดที่มี SVG diagram
- อ่านค่าจาก geoDefs ของรูปทรงที่เลือกโดยตรง
- ทุกช่องตัวเลขที่เปลี่ยนจะทำให้ภาพตัวอย่างถูกสร้างใหม่ทันที
- ปรับสัดส่วนแกน X/Y ตามค่ามิติหลักของแต่ละรูปทรง
- มิติอื่น ๆ มีผลต่อขนาดภาพรวมเพื่อให้ไม่มีช่องกรอกที่เปลี่ยนแล้วภาพนิ่ง
- แสดงค่าทุกช่องพร้อมสีแยกกันใต้ภาพ
- รูปหลายเหลี่ยมไม่สม่ำเสมอวาดจากพิกัดจริง พร้อมเส้นทแยงมุม
- รองรับทั้ง input และ change events
- การคำนวณจริงยังทำงานเมื่อกดปุ่มคำนวณ

ข้อจำกัด:
- ภาพ SVG ของรูปทรงทั่วไปเป็น live preview เพื่อช่วยมองเห็นการเปลี่ยนแปลงของมิติ ไม่ใช่การสร้างรูปทรงตามสเกลเรขาคณิตที่แน่นอนทุกพารามิเตอร์
- รูปหลายเหลี่ยมไม่สม่ำเสมอใช้พิกัดจริง

ตรวจสอบ:
- JavaScript syntax ผ่าน node --check
- ตรวจสอบว่าฟังก์ชัน live preview กลางอยู่ในไฟล์
- ทดสอบ Android browser จริงเพิ่มเติม โดยเฉพาะรูปทรงทุกชนิดและ cache ของ PWA
