TRIGONOMETRY PRO V12.5.0 — VISUAL VECTOR ENGINEERING

ต่อยอดจาก V12.2.0 ตามแผน V12.3–V12.5

เพิ่ม/ปรับปรุง:
1. กราฟพิกัด 2D แสดงค่าติ๊กแกนตั้งแต่ -5 ถึง 5 และสเกลจุดให้ตรงกับตำแหน่งแตะ
2. กรอกตัวเลขโดยตรงหรือแตะภาพกำหนด X,Y ได้
3. เพิ่มการบวกเวกเตอร์ w=u+v และการลบเวกเตอร์ w=u-v
4. เพิ่ม Cross Product u×v สำหรับ 3D เท่านั้น พร้อมแจ้งเตือนหากเลือก 2D
5. เพิ่ม Vector Projection proj_v u = [(u·v)/|v|²]v
6. เพิ่มภาพผลลัพธ์เวกเตอร์ w ในโหมดบวก/ลบแบบแสดงภาพฉาย 2D ขององค์ประกอบ X,Y
7. รักษาฟังก์ชันเดิม: ระยะทาง, ขนาดเวกเตอร์, Dot Product, มุมระหว่างเวกเตอร์, 2D/3D, สูตรและวิธีทำ

ข้อจำกัด:
- ภาพ 3D ในรุ่นนี้ยังเป็นภาพฉายองค์ประกอบ X,Y แบบ 2D และให้กรอก Z ในช่องตัวเลข ไม่ใช่ฉาก 3D ที่หมุนได้
- Cross Product ใช้ 3D เท่านั้น
- Vector Projection รองรับทั้ง 2D และ 3D

ตรวจสอบ:
- JavaScript syntax ผ่าน
- Cross Product ตัวอย่าง (1,2,3)×(4,5,6)=(-3,6,-3)
- Projection ตัวอย่างคำนวณตรงตามสูตร
- ต้องทดสอบ UI และการแตะจริงบน Android เพิ่มเติม
